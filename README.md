# Digitaline IPTV - Next-Gen Digital Streaming

Production web application for **Digitaline IPTV** (`https://www.digitaline-iptv.live/`).

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open your browser to test locally:

```
http://localhost:3000
```

## Production Build

To test or generate the production build:

```bash
npm run build
npm run start
```

## Technology Stack

- Next.js (App Router, Turbopack)
- React
- Tailwind CSS
- Lucide React Icons
